# Project Requirements

## Functional Requirements

- **Automated Medication Delivery**  
  The robot must deliver medications to specific patients, automating the process and reducing nurse workload.
  
- **Accurate Pill Dispensing**  
  The robot must dispense the correct pills to patients, ensuring safe medication delivery.
  
- **Patient Health Monitoring**  
  The robot must measure patient metrics like oxygen levels, blood pressure, and temperature to support care decisions.
  
- **Task Assignment by Nurses**  
  Nurses should be able to assign tasks to the robot, improving efficiency by enabling multiple rounds.
  
- **Autonomous Navigation**  
  The robot must autonomously navigate to rooms, reducing the need for constant supervision.

## Nonfunctional Requirements

- **Reliable Performance**  
  The robot must function consistently to avoid failure in critical hospital settings.
  
- **Scalability**  
  The system should be able to expand with new features or rooms without significant redesign.
  
- **Data Security and Privacy**  
  The robot must secure patient data and communications to comply with privacy regulations.
